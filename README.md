## What Verdant Grove Does

Verdant Grove automates recurring farming activity in an AppleVille-like game environment. Its scripted routines coordinate repetitive actions, allowing the utility to plant, water, harvest, prune, and collect coins with less manual input.

The script can also work through interactive events and wheel-based prompts so a run can continue across different gameplay screens. Configuration profiles make it possible to organize different timing and task arrangements, while the plugin system provides a way to extend the script's behavior. The project is arranged for Windows-based use.
